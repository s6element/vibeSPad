# Soundpad (Shizuku)

Звуки в микрофонный вход других приложений без рута. Работает через Shizuku: процесс с правами shell
регистрирует AudioPolicy (MIX_ROLE_INJECTOR, loopback) и подаёт в него PCM. Всё, что записывает
микрофон (Discord, Telegram, игры, диктофон), получает наш поток вместо физического микрофона.

Статус: код написан, НЕ собирался и НЕ запускался на устройстве. Первый запуск может потребовать правок.

## Требования
- Android 13+ (у shell-пользователя только с 13 есть MODIFY_AUDIO_ROUTING)
- Shizuku (Play Market / GitHub), запущенный через беспроводную отладку
- После каждой перезагрузки Shizuku нужно запускать заново (это ограничение Shizuku без рута)
- Прошивка не должна вырезать shell-доступ к аудио-политике. На MagicOS не проверено

## Сборка
GitHub: залей папку в репозиторий, Actions -> build -> артефакт soundpad-debug (app-debug.apk).
Android Studio: открыть папку, Build -> Build APK.
Локально: `gradle assembleDebug` (Gradle 8.9, JDK 17, Android SDK 35).

## Первый запуск
1. Установи и запусти Shizuku, дай ему работать.
2. Открой Soundpad, дай доступ к микрофону и уведомлениям.
3. «Разрешить Shizuku», затем «Проверка прав». Должно быть MODIFY_AUDIO_ROUTING=есть.
4. Добавь звуки кнопкой «Добавить».
5. Включи «Передавать звук в микрофон». Если не вышло, в нижней строке будет текст ошибки. Пришли его целиком.

## Тест
Локальный, без собеседника:
1. Открой системный диктофон, начни запись.
2. В Soundpad нажми «Тест-тон» (три секунды писков) или любую кнопку.
3. Останови запись и прослушай: писки должны быть в записи, а не только слышны в динамике.

Голосовой чат:
1. Зайди в голосовой канал на этом телефоне, второй участник слушает на другом устройстве.
2. Нажми кнопку (в приложении или на плавающей панели). Собеседник должен услышать звук как твой микрофон.
3. Включи «Подмешивать мой голос», говори и жми кнопки одновременно. Собеседник должен слышать и голос, и эффект.
   В статусе строка «Микрофон, пик» должна показывать ненулевое число, пока говоришь.

## Известные риски
- Названия скрытых API взяты из AOSP, на конкретных прошивках могут отличаться.
- Подмешивание голоса: приложение читает физический микрофон само, а Android может заглушать запись
  фоновым приложениям. Если пик микрофона всегда 0, это оно.
- Пока передача включена, реальный микрофон для всех остальных приложений заменён нашим потоком.
  Выключи переключатель, и микрофон вернётся.
- Shizuku-сервис не демон: закрыл приложение, сервис завершился, микрофон вернулся к норме.
